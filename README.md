# 恐龍展廳 · 博物館驚魂夜

夜班警衛在斷電的史前展廳中，於 1 分鐘內拼回暴龍骨骼的拖曳拼圖遊戲。

## 技術規劃（依設計文件）

| 技術 | 用途 |
|------|------|
| **JavaScript / TypeScript** | 60 秒倒數、拼圖座標、吸附判定 |
| **Framer Motion** | 拖曳與位移動畫 |
| **CSS Keyframes** | 電力閃爍、骨骼螢光效果 |
| **Web Audio** | 倒數滴答聲、詭異爬行環境音 |
| **Zustand** | 剩餘時間、已完成碎片數、遊戲階段 |

## 遊戲流程

1. 進入遊戲 → 2. 倒數啟動 → 3. 觀察與拖曳拼圖 → 4. 拼接骨骼 → 5. 是否全數拼完 → 6. 結算畫面

## 開發

```bash
npm install
npm run dev
```

瀏覽器開啟終端顯示的本地網址即可遊玩。

## 建置

```bash
npm run build
npm run preview
```
